# House2Home Design Sprint

## What This Is

A modified GV 5-day design sprint (Springboard UX bootcamp assignment) for **House2Home** — a platform that helps people confidently decorate their spaces using curated, style-matched "starter kits." The sprint has been expanded beyond the original brief to cover three distinct user personas (Solo Mover, Couple/Roommates, Architect/Interior Designer) and a two-platform architecture (desktop web + mobile AR). Day 1 is complete; Days 2–5 and a final case study remain.

## Core Value

A person who can't confidently decorate on their own should be able to complete a purchase they feel good about in a single session — without needing a designer.

## Context

**Challenge:** House2Home from BitesizeUX (Springboard partnership)
**Sprint format:** Modified GV design sprint, solo practitioner
**Original brief scope:** Single consumer persona, desktop web
**Expanded scope (Day 1 addition):**
- 3 personas: Solo Mover, Couple/Roommates, Architect/Interior Designer
- Platform model: Single product, role-based views (Consumer vs. Pro)
- Desktop: discovery, curation, checkout
- Mobile AR: visualization and placement (optional, connected or standalone)

**Existing work (Day 1):**
- Problem statements defined for all 3 personas
- 4 user flow maps documented (Solo, Couple, Pro, Mobile AR)
- Style discovery mechanism: emoji/word selector → branch (Know it / AI / Gallery)
- Kit selection: A/B comparison × 3 narrows 6 kits to 1
- Collaborative model: individual style finders → shared A/B session
- 11 potential test participants identified (Anna, Orion, Isa, Eli, Nathaniel, Ray, Sadie, Mary, Craig, Seth, Birdie)

**Prior competitor research (Day 2 notes, pre-expansion):**
- Houzz: inspiration good, shopping expensive and separate
- Homestyler: 3D placement but weak style filtering, requires payment for AI
- Planner 5D: similar to Homestyler, no style-based filtering
- Pinterest: great inspiration organization, decent shopping via image search

## Constraints

- **Scope**: Decorative items only ($10–$50) — brief requirement, no furniture
- **Platform**: Desktop web primary, mobile AR secondary — defined in Day 1
- **Timeline**: School assignment with submission deadline
- **Prototype fidelity**: "Realistic facade" — bare essentials to test the flow, not pixel-perfect
- **Testing**: Exactly 5 participants required — course requirement
- **Tool**: Figma preferred for prototype (already in curriculum)

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
